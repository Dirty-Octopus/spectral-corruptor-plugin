# Notes

在 + ADD EFFECT 的 FILTER / UTILITY 分类中添加 Notes，或者搜索 Notes。它是预设说明文本，不参与音频处理，也没有频率范围、Mix 或调制参数。

新建 Notes 直接进入 EDIT，多行输入框接受 Markdown。PREVIEW 在同一个区域显示标题、粗体、斜体、代码、引用、列表、任务清单和链接文字。预设已有正文时，打开 Notes 默认显示预览。正文随预设和宿主工程保存，也随 Notes 的复制、粘贴和跨通道移动保留。

可把 Notes 放在链的任意位置；它不改变效果的音频顺序。每份正文最多 65536 个字符，支持中文和 Unicode。预览使用原生绘制，图片只显示替代文字，HTML 按文本显示；不会加载外部资源。
