# 分频效果缓存审计

FFT Size 和 Frequency Slices 保持原有可选范围。保护针对具体效果的缓存：预算不足时只旁路该效果，其他效果和分频继续运行，界面显示效果名、估算需求和可用预算。

## 维度

令 `B = actual FFT / 2 + 1`，一个 `complex<float>` 为 8 字节。下表是原始有效载荷，不含分配器和容量余量。

| 缓存 | 单个普通效果实例的主要载荷 | 可否在频段间共享 |
| --- | --- | --- |
| Spectral Dispersion | `2 channels × 96 frames × B × 8` | 否，过去的音频必须属于各自频段 |
| Temporal Smear / Time Desync | `64 frames × B × 8` | 否，各段时间历史独立 |
| Frequency Remap | `2 channels × B × (2 doubles + 1 byte)` 相位状态；另有 `B × 8` 临时复数缓冲 | 相位不共享；临时缓冲共享 |
| Remap Formula | 最多 64 条已编译指令、16 个参数及线性公式系数 | 同一效果槽及其全部 slice 共用；无逐 slice 公式表 |
| Partial 基础波形表 | `3 shapes × 11 harmonic levels × 4097 floats`，约 0.52 MiB 表数据 | 全部 Partial 阶段共用；预算约 1.04 MiB 含准备余量 |
| Frequency Shift / Mirror / Warp / Drift、Bin Teleport、Pixelation、Harmonic Match | `B × 8` 复数工作区；部分效果另有小型相位或随机状态 | 工作区共享，运行状态独立 |
| Bin Shuffle | `B × (4 + 8)` 索引与复数工作区 | 共享，每次调用完整覆盖读取区域 |
| Random Bin Death | `B` 字节工作掩码 | 共享 |
| Magnitude Phase Swap | `2 × B × 4` 临时幅度/相位；另有独立历史 | 仅临时区共享 |
| Spectral Bloom | `(2 × B + 1) × 8` 临时权重与前缀 | 共享 |
| Spectral Dropout / Hold / EQ | 持续掩码、保持帧、计数、参数缓存 | 否，跨帧保留 |

例如 actual FFT = 131072 时，B = 65537：一个 Dispersion 的历史约 `2 × 96 × 65537 × 8 = 100664832 bytes`，即 96 MiB。64 段循环分配至四个 CH，每个 CH 最多 16 段；一个 CH 的该效果就约需 1536 MiB 历史。共享临时缓冲无法消除这部分真正独立的时间历史。

`SpectralResourceBudget.h` 对每种效果分别列出缓存尺寸，并额外预留容量余量与对象开销。默认每个插件实例的全部效果缓存共享 256 MiB 预算；界面数字是保守的预算估算，不能等同于操作系统显示的进程常驻内存。基础 STFT、JUCE、界面和参数树内存不属于这个效果缓存预算。未审计的新类型不会获得无限缓存许可。普通时域 Delay/Reverb 的估算也按实际过采样率计算。

## 生命周期与共享边界

- 禁用效果不应准备其大型音频缓存；启用时先核对预算，获准后再准备。
- 同一效果槽中的各 slice 按顺序处理，可共用工作缓冲。共享对象必须拥有稳定地址，移动效果顺序不能留下悬空引用。
- 频谱历史、相位、随机时钟及跨帧状态仍由各 slice 独立持有。
- 分段数被调制时复用已经准备的实例池，避免每 64 samples 来回销毁、分配历史。池容量依据当前需要及已知调制范围准备。
- 整个可达范围能装入预算时预热该范围，之后调制不新增 clone；装不下时，首次到达更高分段数仍可能增长缓存，超预算则旁路对应效果。新增效果的当前需要优先于尚未使用的未来分段缓存。
- 普通 clone 共用同一效果槽的工作区；Partial 阶段还共用分析窗、FFT、单根振荡器工作帧和频谱临时区，分别保留自己的相位和移动历史。
- 仅启用非 Sine 的 Resynth 时准备基础波形表；Sine 不增加该项开销。多个非正弦阶段共用一份表，禁用最后一个请求者后释放。首次启用若无法获得预算，仅旁路请求该表的效果。
- Formula 图结构在控制线程编译，音频侧数值调制只更新固定参数数组；线性公式的系数在下一频谱帧按需更新并由所有 clone 复用。非线性公式直接在实际源频率计算。图像采样精度不生成音频查找表，也不改变缓存预算。
- FFT 几何改变时重新计算预算和缓冲尺寸；不能把旧尺寸的缓存计成新尺寸却继续保留。
- 每个效果的资源状态通过独立的原子状态提供给界面；界面不直接读取音频线程正在修改的效果链。

共享工作区测试使用两个参数不同、输入不同的实例，交错处理多帧及左右声道，并逐频点比较共享版本与独立缓冲版本。它验证的是输出等价性和状态隔离；真实宿主的 CPU 峰值与听感仍需要单独测试。
